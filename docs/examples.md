## Storing a session and using it later

`/history-store` saves a session under the name its client gave it. In another session,
`/history-use NAME` makes it the source for `/history-list` and `/history-copy` in that session
only; `/history-use live` switches back. Nothing is resumed or sent to the model.

The stored session login-fix:

| # | Prompt | Reply |
| --- | --- | --- |
| 1 | Why does the login form reload the page? | The button is inside a <form> with no type, so it submits. |
| 2 | Fix it. | <button type="button">Log in</button> |
| 3 | Anything else? | Also trim the email before sending it. |

*Earlier, in the session the client named "Login fix": store it.*

```text
> /history-store --note "Safari reload bug"
Stored login-fix (3 replies), named after "Login fix".
/Users/you/login-app/.agent-response-history/login-fix
Use it later with: /history-use login-fix (in this folder), or from anywhere: /history-use '/Users/you/login-app/.agent-response-history/login-fix'
```
